# 不打包 APK，直接拷到手机使用

> 结论先说：**只需要拷贝 1 个文件** —— `EnglishTalkApp-单文件版.html`（约 217 KB）。
> 把它放进手机任意目录，用手机浏览器打开即可，不需要服务器、不需要联网、不需要安装。

---

## 一、两个方案，按需选

### 方案 A：单文件版（推荐，最省事）

拷贝这一个文件即可：

```
EnglishTalkApp-单文件版.html     约 217 KB
```

样式、25 个情景数据、离线对话引擎、朗读模块全部已内联在这一个文件里。
**拷到手机 → 用浏览器打开 → 直接可用。**

### 方案 B：完整文件夹（想保留后续扩展能力）

拷贝整个 `EnglishTalkApp` 文件夹（约 230 KB），**目录结构必须保持原样**：

```
EnglishTalkApp/
├── index.html              入口页面
├── css/
│   └── styles.css          样式
├── js/
│   ├── data.js             25 个情景数据 + 年级体系 + 词库
│   ├── partner.js          离线 AI 角色对话引擎
│   ├── speech.js           朗读(TTS) / 语音识别(STT) 封装
│   ├── mic-permission.js   运行时麦克风权限申请（APK 专用）
│   ├── llm.js              云端大模型生成（可选功能）
│   └── app.js              主程序
├── assets/
│   └── icon.svg            图标
├── manifest.webmanifest     PWA 清单（file:// 下无效，可删）
├── sw.js                    Service Worker（file:// 下不注册，可删）
└── 手机直接使用说明.md        本文件（可删）
```

⚠️ **文件夹内部层级不能改**，否则 `index.html` 找不到 `js/` 里的脚本。
如果只想拷最少文件，用方案 A。

## 二、怎么拷到手机

任选一种：

| 方式 | 操作 |
|---|---|
| **USB 数据线** | 手机连电脑 → 选择"传输文件" → 复制进 `Download` 目录 |
| **微信 / QQ** | 发给自己（文件传输助手）→ 手机上长按保存 → 用"其他应用打开" |
| **云盘** | 百度网盘 / 阿里云盘上传 → 手机端下载 |
| **蓝牙 / 隔空投送** | 直接发送文件 |

## 三、手机上怎么打开

**Android（推荐系统浏览器）**

1. 打开「文件管理」→ 找到该 `.html` 文件
2. 点击 → 在弹出列表里选 **浏览器**（Chrome / Edge / 小米浏览器 / 华为浏览器）
3. ❌ 不要选「HTML 查看器」或「文本编辑器」，那样会显示源代码

> 微信内置浏览器（X5 内核）对本地文件和语音支持不完整，建议用系统浏览器。

**iPhone / iPad**

Safari → 文件 App 中找到文件 → 点击打开。iOS 对 `file://` 限制更多，
若遇到朗读无声或无法交互，建议改用下方「https 托管」方案。

## 四、各方案功能可用性

| 功能 | 单文件版 (file://) | 文件夹 (file://) | 打包 APK (Cordova) | https 托管 |
|---|:---:|:---:|:---:|:---:|
| 情景库 25 个（含三年级 10 个） | ✅ | ✅ | ✅ | ✅ |
| 独立练习 · 键盘输入 | ✅ | ✅ | ✅ | ✅ |
| 英文朗读 TTS | ✅ | ✅ | ✅ | ✅ |
| 智能生成 · 离线 | ✅ | ✅ | ✅ | ✅ |
| 外教执行卡 / 评价标准 | ✅ | ✅ | ✅ | ✅ |
| 麦克风语音识别 STT | ❌ | ❌ | ⚠️ 见下注 | ✅ |
| 云端大模型生成 | ❌ | ❌ | ✅ | ✅ |
| 「添加到主屏幕」当 App 用 | ❌ | ❌ | ✅（即 App 本体） | ✅ |
| 完全断网可用 | ✅ | ✅ | ✅ | ✅（首次加载后） |

> **APK 下的麦克风说明**：打包时已内置 `RECORD_AUDIO` 权限声明，并通过
> `cordova-plugin-android-permissions` 在首次点麦克风时**自动弹窗申请**。
> 但语音识别本身依赖设备 WebView 对 Web Speech API 的支持，不同机型表现不一；
> 若某台手机无法识别，可在「设置 → 应用 → 英语口语情景对话 → 权限」中确认麦克风已开启，
> 或改用原生插件 `cordova-plugin-speechrecognition` 替换底层实现（详见
> `cordova/build-apk.md` 第八节）。键盘输入在 APK 内始终可用。

**为什么 file:// 下麦克风和云端生成不能用？**

这是浏览器安全策略，不是本应用的问题：

- **语音识别（STT）**：Web Speech API 的识别部分要求「安全上下文」（https 或 localhost），
  `file://` 协议下浏览器直接禁用。
- **云端生成**：从 `file://` 页面发起的请求，来源标记为 `null`，
  绝大多数大模型服务商会因 CORS 校验拒绝。
- **Service Worker / 添加到主屏幕**：同样要求 https。

朗读（TTS）不属于限制范围，所以**「看情景 → 打字对话 → 听英文朗读」这条主链路在 file:// 下完全可用**。

## 五、常见问题

**Q：朗读没声音？**
Android 需先装英文语音包：
`设置 → 系统 → 语言和输入法 → 文字转语音(TTS) → 安装英语语音数据`。
另外确认媒体音量不为 0、未处于静音/勿扰。

**Q：练习时麦克风按钮是灰的？**
正常现象，`file://` 下语音识别被浏览器禁用。用键盘输入照样能完成全部练习。
想要语音输入，请走下方 https 方案或打包成 APK。

**Q：打包成 APK 后第一次点麦克风没反应 / 提示无权限？**
APK 已声明麦克风权限并在运行时弹窗申请。若误点「拒绝」，请前往
`设置 → 应用 → 英语口语情景对话 → 权限 → 麦克风` 手动开启，再回到练习页即可。
（权限申请逻辑见 `js/mic-permission.js`，与 `cordova/config.xml` 中的
`RECORD_AUDIO` 声明配套。）

**Q：数据会不会丢？**
离线生成、年级筛选等都不写文件，刷新即还原。
只有「云端生成的 API Key」存在浏览器 localStorage 里 —— 清理浏览器数据会丢失，
且 `file://` 模式下各页面共享同一存储空间，不要在不信任的设备上填 Key。

**Q：能给孩子用吗？**
可以。应用不收集任何个人信息，不要求填写住址、学校、联系方式；
三年级情景的语言已按 PEP 三上/三下词表压制（每句 ≤ 8 词）。

## 六、想要完整功能（麦克风 + 云端 + 添加到主屏幕）

不用打包 APK，把文件夹丢到免费静态托管即可，几分钟搞定：

| 平台 | 做法 |
|---|---|
| **GitHub Pages** | 建仓库 → 上传文件夹 → Settings → Pages → 选分支 → 得到 `https://xxx.github.io/...` |
| **Netlify** | 直接把文件夹拖到 netlify.com/drop，立刻得到 https 链接 |
| **Vercel / Cloudflare Pages** | 类似，导入文件夹即可 |

之后手机访问该 https 链接 → 菜单「添加到主屏幕」，
体验与 APK 基本一致（图标、全屏、离线缓存），只是没有应用商店外壳。

> 提示：这样托管后内容是公开的链接，请勿在链接里放置隐私信息；
> 云端 API Key 建议改由自己的后端代理转发。
